Boilerplate

Short: Tall Poppy Studio is an independent software studio in Budapest, run by Akos Komuves. It makes native apps and AI tooling.

Long: Tall Poppy Studio is the independent software studio of Akos Komuves, a software engineer in Budapest, Hungary, with about ten years of shipping production software at companies including Tier, ABC News, Queensland Police Service and Liven. The studio publishes its own apps, among them WikiCatch, WikiHunt, NoteHunter, MeritValue, Kufu, Matchframe and Kumano, open-source MCP servers for App Store work, and builds software for clients.
