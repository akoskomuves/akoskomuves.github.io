Open source

Tools for building apps with AI agents.

The studio publishes the tools it builds for its own work: MCP servers that let an AI coding agent talk to App Store Connect and App Store search data, and agent skills for App Store keywords and company valuation. All MIT licensed.

appstoreconnect-mcp

MCP · TypeScript · MIT

An MCP server for the App Store Connect API. Manage prices (including purchasing-power-parity rebalancing across territories), subscriptions and offers, TestFlight builds and app metadata from an AI coding agent.

npx -y @akoskomuves/appstoreconnect-mcp

npm · GitHub · 3,225 npm downloads in the last 30 days · 5 GitHub stars · v1.13.0

kranked-mcp

MCP · Python · MIT

App Store keyword research for your AI coding assistant. Ask Claude, Cursor or any MCP client how hard a keyword is, how popular it is and where your app ranks. Runs locally on Apple’s public endpoints, no account or API key.

claude mcp add kranked -- uvx kranked-mcp

PyPI · GitHub · 86 PyPI downloads in the last 30 days · v0.2.3

aso-cross-localization

Claude Code skill · Python · MIT

A Claude Code skill for App Store cross-localization. Stack keywords in the secondary localizations each App Store storefront indexes: locale tables, a scoring playbook and a validator for the bundle.

GitHub

meritvalue-skills

Agent skills · MIT

Skills for valuing public companies like an owner. Free frameworks for moats, DCF, reverse DCF and expected return. Connect the MeritValue MCP for reproducible numbers from SEC filings.
