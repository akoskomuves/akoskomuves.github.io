Studio badge

“A Tall Poppy Studio app”

A small badge for the footer of every Tall Poppy product site. It links back to the apps page with a ?ref= tag, so the studio can see which site sent a visitor, and the apps page greets them by name.

Preview

The text and stem take the colour of the surrounding footer text, so the badge sits in each product’s own palette. The petals stay poppy red.

HTML snippet
